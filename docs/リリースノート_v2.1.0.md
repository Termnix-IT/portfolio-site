# v2.1.0 — Contact Form and Repository Cleanup

問い合わせフォームの実装と、リポジトリ構造・デプロイ workflow の整理を行ったマイナーリリースです。

## Highlights

- `contact.html` に AWS Lambda Function URL へ送信する問い合わせフォームを追加
- 静的サイト構成を維持したまま、`static/main.js` から JSON POST する送信処理を実装
- 返信先メールアドレスを任意入力に変更し、問い合わせしやすいフォームに調整
- 運用ドキュメントを `docs/` に集約し、ルート直下を公開ページ中心の構成に整理
- `ToolBox.html` / `Diagram.html` を `toolbox.html` / `diagram.html` に小文字統一
- GitHub Actions の deploy bundle 作成を allowlist 方式に変更し、公開対象を `*.html` と `static/` に限定

## Contact Form

| 項目 | 内容 |
|---|---|
| 対象ページ | `contact.html` |
| 送信方式 | AWS Lambda Function URL への `fetch()` JSON POST |
| 送信項目 | `name`, `email`, `topic`, `message`, `_gotcha` |
| spam 対策 | honeypot 用 `_gotcha` フィールドを追加 |
| UI 状態 | 送信中、成功、失敗メッセージを表示 |
| タイムアウト | `CONTACT_REQUEST_TIMEOUT_MS` を 10 秒に設定 |

フォーム送信中はボタンを無効化し、送信完了後は入力内容をリセットします。送信失敗時はユーザー向けに再試行を促すメッセージを表示します。

## Repository Structure

ルート直下に混在していた運用系ドキュメントを `docs/` に移動しました。

```text
Portfolio_Web/
├─ index.html
├─ portfolio.html
├─ toolbox.html
├─ diagram.html
├─ contact.html
├─ static/
├─ docs/
│  ├─ DEPLOYMENT.md
│  ├─ MAINTENANCE.md
│  └─ security_best_practices_report.md
├─ .github/workflows/
└─ README.md
```

これにより、ルート直下は公開 HTML と主要設定に寄せ、保守・デプロイ・セキュリティ関連の文書は `docs/` に集約しています。

## Deployment

GitHub Actions の deploy workflow を見直し、公開対象だけを `_site/` にコピーする方式に変更しました。

```bash
rsync -av ./*.html _site/
rsync -av ./static/ _site/static/
```

これにより、`docs/`, `README.md`, `.github/`, `.gitignore` などの公開不要ファイルは bundle に含まれません。

また、過去に削除済みだった GitHub Pages deploy job の方針に合わせ、ドキュメント上の記述も AWS S3 + CloudFront 前提に統一しました。
