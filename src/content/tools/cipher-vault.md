ローカル動作を前提にしたパスワード管理アプリです。データは自端末の SQLite に保存し、外部サーバーへ送信しない構成です。ログインに加えて、API キー、クレジットカード、銀行/証券（ログイン用と取引用のパスワード、第2暗証番号などの追加の秘密）を種類別に保存でき、検索とグループ表示、パスワード生成、クリップボードコピー、自動ロックに対応しています。全項目を暗号化する新形式の保管庫への移行、専用パスフレーズで保護する暗号化バックアップ（.cvault 形式）と空の保管庫への復元、弱いパスワードや使い回しを端末内で調べる「パスワードの点検」も備えています。

パスワードやカード番号などの秘密値は伏せ字で扱い、目のアイコンを続けて2回押したときだけ表示します。コピーした内容は30秒後かロック時にクリップボードから消し、秘密値は検索の対象にも含めません。v0.5.0 では、保管庫を操作できるのを本人の画面操作だけに絞るため、ほかのアプリから保管庫へつなぐ外部接続の機能を削除しました。v0.9.0 では、保管庫の暗号化・保存・解除などの処理を Electron から Rust（Tauri）に作り直し、旧実装と同じ入力に同じ結果を返すことを両方の実装を比べる試験で確かめています。保管庫の形式は変えていないため、Electron 版の保管庫をそのまま開けます。

Windows 向けの setup / portable 配布に対応し、GitHub Releases から入手できます。setup 版は「ヘルプ」→「バージョンと更新」から手動で更新する方式で、起動時に勝手に更新を適用することはありません。最新の v0.9.0 からは、ダウンロードした setup の更新用の署名を確かめてから適用し、署名がない、または合わない更新は適用しません。v0.9.0 の setup は Electron 版を自動でアンインストールしてから保管庫を引き継ぎます。見た目は従来のシンプルなデザインと、色がゆっくり移り変わる「ルミナス」デザインを切り替えられます（OS の動きを減らす設定に対応）。配布物はコード署名されていないため、初回の起動で SmartScreen の警告が出る場合があります。
