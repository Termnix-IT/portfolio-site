ローカル動作を前提にしたパスワード管理アプリです。データは自端末の SQLite に保存し、外部サーバーへ送信しない構成で、保管庫のロック・解錠、エントリ管理、パスワード生成、クリップボードコピー、自動ロックに対応しています。専用パスフレーズで保護する暗号化バックアップ（.cvault 形式）と空の保管庫への復元、弱い・重複・古いパスワードを端末内で点検するセキュリティ監査と SECURITY SCORE も備えています。

監査は外部へのパスワード送信や漏えい情報の照会を行わず、復元は全件を検証してから一括保存し、誤パスフレーズや改ざん、書き込み失敗時にはデータを追加しない設計にしています。v0.2.4 では、ローカルの Web/API に外部のページから保管庫のリセットなどを送り込まれないよう、接続先と送信元の検査と CSRF トークンを必須にしました。Electron 側もすべての IPC で送信元の画面を検証し、外部ページへの遷移や新しいウィンドウを拒否します。パスワードは目のアイコンを続けて2回押したときだけ表示し、保存・生成・ロックなどの際には伏せ字に戻します。

Electron 版として Windows 向けの setup / portable 配布に対応し、GitHub Releases から起動用ファイルを取得できます。setup 版は「ヘルプ」→「アプリ情報 / 更新」から手動で更新する方式で、起動時に勝手に更新を適用することはありません。最新の v0.2.5 では、エントリの選択や保存・コピーの完了を短いアニメーションで示すようにしました（OS の動きを減らす設定に対応）。配布物はコード署名されていません。
