Codex と Claude Code を中心に、AI サービスのサブスクリプション利用枠を自動で取得し、5時間枠と週間枠の残り割合をひとつの小さな画面で確認できる Windows 向けデスクトップアプリです。2つの AI コーディングツールを併用していると、どちらの枠があとどれだけ残っているかを確かめるたびに別々の画面を開く必要があったため、常駐させて一目で判断できるダッシュボードとして作りました。

初期設定では Codex を青、Claude Code をオレンジの二重リングで表示し、オプションからリングを1～3本に変え、表示するサービスと色、最初に出す枠を選べます。Z.AI Coding Plan、Kimi Code、Command Code、OpenCode Go なども選択肢にありますが、これらは取得形式とテストデータに基づく対応で、実契約アカウントでの残量取得は未検証です。中央のアイコンのクリックやホイールで表示するサービスを、中央の数値や枠のラベルのクリックで枠を切り替えられ、リセットまでの残り時間も表示します。透明・非装飾のウィンドウと、リングだけを表示するミニマル表示で、作業の邪魔にならないようにしています。ミニマル表示のリングの大きさはオプションで変えられ（72～360px）、調整中は実際のリングと同じ見た目のプレビューを重ねて表示します。最初の正式版の v1.0.0 では、タイトルバーが隠れるミニマル表示でも操作できるよう、右クリックで表示の切り替え・最前面の固定・再読み込み・オプションなどを選べるメニューを付け、1列に長く並んでいたオプション画面を「リング」「表示」「アプリ」の3つのタブに分けました。

残量は Codex CLI の app-server と、アプリに同梱した OpenUsage から読み取り、Codex は1分、ほかは5分ごとに更新します。取得頻度の制限（429）には間隔を広げて再試行し、取得結果はメモリ上だけに保持してディスクへ保存しません。v0.1.14 では Claude Code の認証期限切れを検出したとき、インストール済みの CLI を画面に出さずに起動して認証の更新を試みるようにしました。認証ファイルを直接書き換えず、更新は CLI 自身に任せています。v0.1.15 では、取得のたびにセッションログ全体を解析していたために時間切れで「通信失敗」と表示される問題を直し、約1.6GB のログがある環境で取得時間を約11秒から約2秒に縮めました。v0.1.16 からは、オプションの「更新を確認」から、インストーラーの署名を検証したうえでアプリ内で更新・再起動できます。確認も更新もボタンを押したときだけ実行し、旧版からのアプリ内更新は v0.1.18 の公開後に実機で確かめています。v0.1.18 では、同梱の OpenUsage が Claude Code の利用率を共通のキャッシュファイルへ書き込んだり、自動検出したアカウントを設定ファイルへ保存したりしないようにし、画面側から任意のファイルを読み書きできる権限を外して表示設定の読み書きを専用のコマンドに限定しました。配布版には Content Security Policy も設定しています。ただし、認証の自動復旧の一連の動作は未検証です。Windows x64 向けのインストーラーと SHA-256 チェックサムを配布しています。
