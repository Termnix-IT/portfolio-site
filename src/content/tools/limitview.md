Codex と Claude Code を中心に、AI サービスのサブスクリプション利用枠を自動で取得し、5時間枠と週間枠の残り割合をひとつの小さな画面で確認できる Windows 向けデスクトップアプリです。2つの AI コーディングツールを併用していると、どちらの枠があとどれだけ残っているかを確かめるたびに別々の画面を開く必要があったため、常駐させて一目で判断できるダッシュボードとして作りました。

初期設定では Codex を青、Claude Code をオレンジの二重リングで表示し、オプションからリングを1～3本に変え、表示するサービスと色、最初に出す枠を選べます。Z.AI Coding Plan、Kimi Code、Command Code、OpenCode Go なども選択肢にありますが、これらは取得形式とテストデータに基づく対応で、実契約アカウントでの残量取得は未検証です。中央のアイコンのクリックやホイールで表示するサービスを、中央の数値や枠のラベルのクリックで枠を切り替えられ、リセットまでの残り時間も表示します。透明・非装飾のウィンドウと 200×200 のミニマル表示で、作業の邪魔にならないようにしています。

残量は Codex CLI の app-server と、アプリに同梱した OpenUsage から読み取り、Codex は1分、ほかは5分ごとに更新します。取得頻度の制限（429）には間隔を広げて再試行し、取得結果はメモリ上だけに保持してディスクへ保存しません。v0.1.14 では Claude Code の認証期限切れを検出したとき、インストール済みの CLI を画面に出さずに起動して認証の更新を試みるようにしました。認証ファイルを直接書き換えず、更新は CLI 自身に任せています。v0.1.15 では、取得のたびにセッションログ全体を解析していたために時間切れで「通信失敗」と表示される問題を直し、約1.6GB のログがある環境で取得時間を約11秒から約2秒に縮めました。最新の v0.1.16 では、オプションの「更新を確認」から、インストーラーの署名を検証したうえでアプリ内で更新・再起動できます。確認も更新もボタンを押したときだけ実行します。ただし、GitHub Releases からの実際のアプリ内更新と、認証の自動復旧の一連の動作は未検証です。Windows x64 向けのインストーラーと SHA-256 チェックサムを配布しています。
