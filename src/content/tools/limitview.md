Codex と Claude Code のサブスクリプション利用枠を自動で取得し、5時間枠と週間枠の残り割合をひとつの小さな画面で確認できる Windows 向けデスクトップアプリです。2つの AI コーディングツールを併用していると、どちらの枠があとどれだけ残っているかを確かめるたびに別々の画面を開く必要があったため、常駐させて一目で判断できるダッシュボードとして作りました。

Codex は青、Claude Code はオレンジの二重リングで残量を表示し、中央のアイコンのクリックやホイールで表示するサービスを、中央の数値や枠のラベルのクリックで5時間枠と週間枠を切り替えられます。リセットまでの残り時間も表示し、透明・非装飾のウィンドウと 200×200 のミニマル表示で作業の邪魔にならないようにしています。ミニマル表示の数値には暗い縁取りを付け、明るい壁紙の上でも読めるようにしました。

残量は Codex CLI の app-server と、アプリに同梱した OpenUsage から読み取り、Codex は1分、Claude Code は5分ごとに更新します。Claude の利用枠 API が取得頻度の制限（429）を返した場合は、5分・10分・20分・最大30分と間隔を広げて再試行し、取得制限・認証拒否・サーバー障害・通信失敗を区別して原因と復旧手順を示します。一時的な失敗では直前の残量を保持し、古い値であることと最終取得時刻を表示します。タイムアウトやアプリ終了時には起動した取得用プロセスを子孫まで停止し、同梱する OpenUsage はビルド時にバージョンを固定してチェックサムを検証します。取得結果はメモリ上だけに保持してディスクへ保存しない設計です。v0.1.12 では Windows x64 向けインストーラーと SHA-256 チェックサムを配布し、アプリ内のオプションから公開版の更新を手動で確認できます。
